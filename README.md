# GPO External Vision Macro - True Demon Baal

Macro esterna basata su Computer Vision (OpenCV) e PyAutoGUI per Grand Piece Online (Roblox).

## Requisiti
- Python 3.11+
- Esecuzione con privilegi di Amministratore (necessario per `pynput` / `keyboard`)

## Installazione Locale
```bash
pip install -r requirements.txt
python main.py
